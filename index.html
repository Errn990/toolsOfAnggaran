Tools Kertas Kerja Anggaran

Unggah file monitoring (.xls dari Oracle BI) dan kertas kerja (.xlsx). Pengisian dan perbaikan berjalan otomatis di browser Anda, lalu hasilnya siap diunduh. File tidak dikirim ke server mana pun.

Tarik file ke sini atau klik untuk memilih
Monitoring dan kertas kerja, boleh lebih dari satu
Browser Anda terlalu lama untuk fitur ini. Gunakan Chrome, Edge, Firefox, atau Safari versi terbaru.

Yang dikerjakan otomatis

  • Mengisi sel kosong di sheet INVESTASI dari monitoring (kontrak, vendor, deskripsi, PR, PO, RID, tanggal, nilai). Pasangan dicari lewat nomor task dan budget.
  • Rumus error (#DIV/0!, #N/A, #VALUE!, #NAME?, #REF!, termasuk rumus bersama) diperbaiki otomatis. SUM yang rusak dipulihkan dari rumus kolom sebelahnya.
  • Ukuran tabel, format, validasi data, dan link eksternal tidak berubah. Data yang sudah ada tidak ditimpa.
